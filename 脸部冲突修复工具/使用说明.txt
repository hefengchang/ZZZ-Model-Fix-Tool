# ZZZ 角色 Mod 冲突修复工具 — 使用说明

作者：踩蘑菇网 绿林小子

修复不同角色的 Mod 互相冲突（导致其他角色面部/模型丢失）的问题。
程序只处理 vb.txt 中列出的哈希，修复前自动备份，失败时不修改文件。

## 使用方法

```
直接运行程序（不带参数）     → 自动修复当前目录下所有 Mod，推荐只在单个mod文件夹下修复
把 Mod 文件夹拖到程序上       → 自动修复该文件夹
程序路径 文件夹1 文件夹2     → 修复指定的多个文件夹
程序路径 --dry-run          → 只预览，不实际修改
```

- 修改前自动备份：原文件保存为 `同名.ini.bak`
- 自动跳过 `DISABLED*` 开头的文件
- 找不到对应 blend 节、或 blend 哈希与 vb.txt 不一致时：**不修改文件**，只提示（按提示把新哈希追加到 vb.txt 后重新运行即可）
- 游戏更新后哈希变动：在 vb.txt 对应角色名下追加新哈希即可（无需删除旧的）

## 恢复备份

程序每次修改前都会把原文件备份为 `.bak` 文件（与被修改的 ini 同目录、同名）。

**恢复方法**：把 `xxx.ini.bak` 改名为 `xxx.ini` 覆盖当前文件即可还原修改前的状态。

例如：
```
修复前:  hair.ini        （原文件）
修复后:  hair.ini        （已修复）
         hair.ini.bak    （自动备份的原文件）

还原:    把 hair.ini.bak 改名为 hair.ini（覆盖），即恢复原配置
```

> 提示：`.bak` 备份文件不会被 Mod 加载器读取，留在文件夹内不影响游戏。
