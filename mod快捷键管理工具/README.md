# 绝区零mod快捷键管理工具

一款用于管理 3DMigoto / ZZMI mod 快捷键的 Windows 小工具。自动读取 mod 的 ini 快捷键，集中查看、修改按键、起中文名、调整默认值，并保存多套快捷键状态。

不需要手动翻 ini 文件，也不需要记住哪一行对应哪个功能。可为每个mod生成菜单面板。

## 功能

- 自动扫描 mod 的 ini，列出每个快捷键的内部名、识别名、按键、中文说明、游戏当前值、默认值、可选值等。
- 按键可重新绑定：直接按键盘上的键或组合键，松开自动保存。
- 支持组合键与 3DMigoto 的 `no_*` / `no_modifiers` 写法。
- 支持识别和捕获 Xbox 手柄按键 `XB_...`，显示中文说明。
- 可给快捷键起中文识别名，不影响原 ini 的功能。
- 可修改默认值，并校验是否在该快捷键的可选值范围内。
- 仪表盘显示游戏当前值（读取 `d3dx_user.ini`）。
- 保存多套快捷键状态，随时选择恢复。
- 把当前游戏值一键设为启动默认，缓解中文路径导致的状态丢失。
- 按键检测区分“同条件一键切换多个状态（正常，已标绿）”和“条件不同的真冲突（标红）”；功能正常时无需修改。
- 自动生成快捷键表格 txt，方便分享和查阅。
- 支持拖拽 mod 文件夹、Mods 文件夹或 ini 到窗口。
- 自动刷新：游戏内按 F10 保存后，工具会自动更新当前值。
- 可为没有面板的 mod 生成右下角图片菜单面板，游戏内按快捷键显示全部快捷键说明。

## 系统要求

- Windows 10 / 11。
- 使用发布版 exe 时不需要安装 Python。
- 从源码运行需要 Python 3.9 及以上，仅使用标准库（tkinter）。

## 下载与运行

### 发布版（推荐）

1. 下载 `mod快捷键管理工具.exe`。
2. 放到任意文件夹，双击运行。
3. 启动时不会自动扫描目录，请先选择或拖入 mod 目录。

### 从源码运行

```cmd
python mod快捷键管理工具.py
```

## 快速开始

1. **选择模组目录**
   - 最省事：选择 `ZZMI\Mods` 文件夹，程序会自动展开角色分类，逐个列出真正的 mod。
   - 也可以选择单个 mod 文件夹，或直接把文件夹 / ini 拖进窗口。
2. **确认 ZZMI 根目录**
   - 即包含 `d3dx_user.ini`、`d3dx.ini` 和 `Mods` 的目录，例如 `E:\ZZMI`。
   - 选中 mod 目录后会自动向上查找；找不到可手动浏览或点“自动检测”。
3. **开始管理**
   - 左侧选 mod，右侧看快捷键。
   - 第一次点击单元格是选择，再点一次打开编辑框。

## 界面说明

### 顶部

- **模组目录（可拖入）**：当前扫描的目录。留空时不会扫描任何文件。
- **自动刷新**：默认开启，监听 ini 与 `d3dx_user.ini` 的变化。
- **ZZMI 根目录**：读取游戏当前值所需。未设置时仍可查看和修改按键，只是不显示游戏当前值。

### 左侧模组列表

- 可按模组名、分类、路径搜索。
- 支持点击列头排序：模组、分类、按键数、面板、状态。
- `DISABLED` 开头的 mod 显示为禁用状态。
- 没有快捷键的纯贴图 / UI mod 也会列出，按键数为 0。

### 快捷键表格

默认显示这些列：

| 列 | 说明 | 是否可改 |
|---|---|---|
| 内部名（固定） | ini 中的 `[Key...]` 段名 | 否 |
| 识别名（可改） | 段头后面的中文备注，方便识别 | 是 |
| 按键（可改） | 实际触发按键 | 是 |
| 中文说明 | 按键的中文描述，如“Ctrl + 句号键” | 否 |
| 游戏当前值 | 从 `d3dx_user.ini` 读取的当前状态 | 否 |
| 默认值（可改） | 游戏启动时使用的初始值 | 是 |
| 可选值 | 该快捷键允许的取值 | 否 |

点“显示更多列”可展开切换方式、生效条件、所在文件。

### 工具栏

- **保存当前状态**：把当前 mod 的整套快捷键设置存一份。
- **选择已有状态**：从已保存的状态列表里选一套恢复。
- **当前值设为默认**：把游戏里的当前值写入 ini 默认值。
- **撤销到上一步**：撤销本次运行中的修改。
- **更多**：恢复原档、恢复所选默认、恢复全部默认、打开 ini、打开模组文件夹。

## 快捷键编辑规则

### 重新绑定按键

1. 单击“按键”单元格。
2. 直接按键盘上的键或组合键，也可以按手柄按键。
3. 松开后约 0.5 秒自动保存。

示例：

```ini
key = ctrl no_shift no_alt .
key = ctrl no_shift no_alt z 1
key = no_modifiers y
```

- 同时按住 Ctrl、Z、1 会写成 `ctrl z 1`，表示三个键同时按下。
- 未按下的 Ctrl / Shift / Alt 会自动补 `no_ctrl` / `no_shift` / `no_alt`。
- 单个普通键使用 `no_modifiers`。
- 不会自动添加备用键；需要多个备用键请直接编辑 ini。

### 手柄按键

- 支持识别 Xbox 手柄按键：`XB_A`、`XB_B`、`XB_X`、`XB_Y`、`XB_START`、`XB_BACK`、`XB_GUIDE`、`XB_LEFT_TRIGGER`、`XB_RIGHT_TRIGGER`、`XB_LEFT_SHOULDER`、`XB_RIGHT_SHOULDER`、`XB_LEFT_THUMB`、`XB_RIGHT_THUMB`、`XB_DPAD_UP/DOWN/LEFT/RIGHT`。
- 可带手柄编号：`XB2_A` 表示 2 号手柄的 A 键。
- 中文说明列显示为“手柄 A 键”“手柄 左扳机”等。
- 按键捕获支持手柄：单击按键单元格后直接按手柄键，松开自动保存。
- 同时按多个手柄键会写成一行，例如 `XB_A XB_LEFT_SHOULDER`。
- 一次捕获只用一种输入：先按键盘就锁定键盘，先按手柄就锁定手柄；要换源按 Esc 重来。
- 进入捕获时已按住的手柄键不会算作输入，需松开后重新按。

### 冲突检测

- **同条件共用按键**：同一生效条件下多个快捷键使用相同按键，会一键切换多个状态，属正常设计。行标浅绿，状态栏和详情会说明“已标绿”；功能正常无需修改。
- **条件不同但按键相同**：标红提醒，可能互相冲突；捕获到这种按键时拒绝保存并提示。功能正常时同样无需修改。
- 工具只提醒。

### 面板 mod

检测到 mod 自带快捷键面板时：

- 按键锁定，避免破坏面板逻辑。
- 识别名和默认值仍可修改。
- 面板快捷键会在提示行显示。

## “状态”与“默认值”

- **状态**：一套完整的快捷键设置，可保存多套，保存在 mod 目录内。
- **游戏当前值**：3DMigoto 当前实际使用的值，来自 `d3dx_user.ini`。
- **默认值**：没有已保存状态时，游戏启动使用的值，来自 ini 的 `[Constants]`。

推荐流程：

1. 在游戏里切换好状态。
2. 按 `F10`，或完全退出游戏，让 3DMigoto 写入 `d3dx_user.ini`。
3. 回到工具，等自动刷新或点“重新扫描”。
4. 确认“游戏当前值”正确。
5. 点“保存当前状态”，起个名字。

以后恢复：

1. 完全退出游戏。
2. 点“选择已有状态”，选一套，恢复。
3. 再启动游戏。

### 中文路径导致状态丢失

3DMigoto 对含中文路径的持久状态支持不稳定，可能出现：

- 写不进 `d3dx_user.ini`；
- 下次启动读不到；
- mod 不存在时状态被清除。

应对方法：在游戏里调好后按 F10，回工具点“当前值设为默认”。这会把当前值写入 mod ini 的默认值，下次启动即使持久化失效也会使用这套设置。写入前会自动创建原档备份，可撤销。

## 图片菜单面板

给没有快捷键面板的 mod 增加一个游戏内右下角图片菜单面板，显示该 mod 的全部快捷键。

1. 选中一个没有面板的 mod。
2. “更多 → 添加图片菜单面板”。
3. 设置切换按键。单条件时默认 `no_modifiers /`；多条件时默认 `alt no_ctrl no_shift /`，可在弹窗内重新按键。
4. 生效条件只能从下拉列表选择，不能手动输入。
   - 只有一个条件时自动选中。
   - 多个条件时初始为空，由用户选择，推荐项标有“（推荐）”。
5. 点“添加”，回游戏按 F10 重新加载 mod。

规则：

- 只能用于没有快捷键面板的 mod。
- 必须有至少一个生效条件；没有任何 condition 的 mod 直接拒绝生成。
- 不提供“自动判断”，也不能手动输入或自定义条件。
- 面板首行显示 mod 路径，从 `Mods` 一层开始，不写 `Mods` 之前的目录；第二行是“快捷键列表”。
- 面板内容包含全部快捷键，文字多时自动缩小字号，必要时分两列。
- 修改按键或识别名后，图片会自动重画；游戏内需按 F10 或重新进入才显示新图。

“更多 → 移除图片菜单面板”会删除 ini 中注入的配置和生成的图片、着色器文件，不影响 mod 原有内容。

如果面板不显示，先确认游戏日志里没有着色器错误，并检查该条件在游戏内是否为 1。

## 生成的文件

所有工具生成的文件都放在对应 mod 内的 `快捷键管理` 文件夹：

```text
<mod目录>\快捷键管理\
├─ 快捷键_<模组名>.txt      # 快捷键表格，自动生成
├─ 快捷键状态.json          # 保存的状态
├─ DISABLED_<ini>_原档.ini  # 首次修改前的原档备份
├─ zzmi_hotkey_image.png    # 图片菜单面板（添加面板后）
└─ zzmi_hotkey_image.hlsl   # 图片菜单面板着色器（添加面板后）
```

- `DISABLED_` 前缀让游戏和工具都不会加载原档。
- 原档只在首次修改该 ini 时创建，之后不会覆盖。
- 不使用全局配置，不写注册表，不在 mod 外保存数据。
- 点“打开模组文件夹”可进入 mod 根目录。

## 支持的目录结构

```text
1. 平铺
Mods\ModA\a.ini

2. 分类
Mods\角色分类\ModA\a.ini

3. 分类 + 多部件
Mods\角色分类\ModA\部件1\a.ini
Mods\角色分类\ModA\部件2\b.ini
→ 整个 ModA 算一个模组

4. 混合
Mods\ModA\a.ini
Mods\角色分类\ModB\b.ini
```

- 任意层级以 `DISABLED` 开头的 ini 或子文件夹都会被跳过，大小写不敏感。
- 工具自己的 `快捷键管理` 文件夹不会被当成 mod 扫描。

## 注意事项

- **修改 ini、恢复状态前请完全退出游戏**，否则游戏退出时可能覆盖写入。
- 游戏运行中 `d3dx_user.ini` 可能不是实时值；按 F10 后才写入。
- 启动时不会自动扫描目录，避免大文件夹卡顿；请手动选择或拖入。
- 快捷键编辑只写入一条 `key =` 行，不会自动生成备用键。
- 默认值必须在可选值范围内，越界不会保存。
- 原档备份是唯一的一份；如需额外备份，请自行复制 `快捷键管理` 文件夹。

## 常见问题

**Q：没找到 `d3dx_user.ini`，当前值显示 `—`？**

先运行一次游戏，或手动把 ZZMI 根目录设为包含 `d3dx_user.ini` 的文件夹（例如 `E:\ZZMI`）。按键和默认值仍可正常编辑。

**Q：改了按键但游戏里不生效？**

- 确认修改的是当前启用路径下的 mod，文件夹改名后旧状态不会沿用。
- 检查 mod 是否以 `DISABLED` 开头（禁用状态）。
- 检查快捷键的“生效条件”是否满足。
- 确认没有和其他快捷键冲突。

**Q：为什么按键无法修改？**

该 mod 可能带有快捷键面板，工具会锁定按键以防破坏面板。识别名和默认值仍可修改。

**Q：保存的状态在哪里？会跟着 mod 走吗？**

在 mod 目录下的 `快捷键管理\快捷键状态.json`。整个 mod 文件夹移动或改名时，状态会一起移动。

**Q：为什么启动后列表是空的？**

工具不会自动扫描。请选择 `ZZMI\Mods`、具体 mod 文件夹，或把文件夹 / ini 拖进窗口。

**Q：提示“默认值不在可选值内”？**

该快捷键只允许特定取值。请从“可选值”列选择一个合法值，或先确认 ini 中的选项定义。

## 从源码打包

需要 Python 3.9+ 和 PyInstaller：

```cmd
pip install pyinstaller
```

安装后执行：

```cmd
pyinstaller --noconfirm --clean --onefile --noconsole --name "mod快捷键管理工具" "mod快捷键管理工具.py"
```

生成的 exe 为无命令窗口版本。
